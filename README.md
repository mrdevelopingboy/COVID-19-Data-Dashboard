# 🦠 COVID-19 Analytics Dashboard

### 📊 Interactive Data Analysis & Visualization Using Python

An interactive dashboard built using **Python, Streamlit, Pandas, and Plotly** to explore COVID-19 trends, compare countries, and visualize vaccination statistics.

## 🌟 Project Overview

The COVID-19 Analytics Dashboard transforms sample COVID-19 data into meaningful visualizations through interactive charts and dynamic filters.

It demonstrates practical skills in data analysis, data processing, and dashboard development.

## ✨ Key Features

- 📈 COVID-19 trend analysis
- 🌍 Country-wise and region-wise comparisons
- 💉 Vaccination rate analysis
- 📊 Interactive charts and KPI metrics
- 🔍 Dynamic country, region, and date filters
- 📥 Downloadable filtered CSV dataset

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| Python | Core programming |
| Streamlit | Interactive dashboard |
| Pandas | Data processing and analysis |
| Plotly | Data visualization |
| CSV | Dataset storage |

## 📊 Dashboard Visualizations

1. COVID-19 Trends — Interactive line chart
2. Country Comparison — Bar chart

4. Vaccination Analysis — Bar chart
5. Data Explorer — Filtered data table

## 💻 Run Locally

**1. Install dependencies**

```bash
py -m pip install -r requirements.txt
```

**2. Start the dashboard**

```bash
py -m streamlit run dashboard.py
```

**3. Open in your browser**

http://localhost:8501

Run these commands inside the `COVID19_Data_Dashboard_Project` folder.
